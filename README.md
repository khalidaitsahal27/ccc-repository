# CCC Repository

A lightweight demo website showcasing a simple web page and GitHub-based project automation.

## Overview

This repository contains a web page rendered from `index.html`, a CSS stylesheet dependency, and two GitHub Actions workflows. It is designed as a clear, minimal example of a website project hosted and maintained with GitHub.

## Features

- A simple website built around `index.html`
- CSS styling through a stylesheet dependency
- Two GitHub Actions workflows for repository automation
- A publicly accessible live demo

## Live Demo

[Open the CCC Repository website](https://ccc-repository.khalidsahal27.workers.dev/)

## Run Locally

Open `index.html` in a web browser to view the page locally.

# مستودع CCC

موقع تجريبي بسيط يعرّف بصفحة ويب خفيفة وأتمتة المشروع باستخدام GitHub.

## نبذة عن المشروع

يحتوي هذا المستودع على صفحة ويب يتم عرضها من خلال الملف `index.html`، واعتماد لملف تنسيق CSS، بالإضافة إلى مساري عمل باستخدام GitHub Actions. يقدّم المشروع مثالًا واضحًا ومختصرًا لموقع ويب تتم إدارته وتطويره عبر GitHub.

## المزايا

- موقع بسيط يعتمد على الملف `index.html`
- تنسيق الصفحة باستخدام ملف CSS
- مسارا عمل من GitHub Actions لأتمتة مهام المستودع
- نسخة منشورة يمكن زيارتها مباشرةً

## النسخة المنشورة

[زيارة موقع مستودع CCC](https://ccc-repository.khalidsahal27.workers.dev/)

## التشغيل محليًا

افتح الملف `index.html` باستخدام متصفح الويب لعرض الصفحة على جهازك.
